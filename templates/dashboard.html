API Reference

Endpoints used by the OnyxBridge Android app
POST /api/register

Register a new device or update an existing one. Accepts device_id, name, model, os_version, app_version.

POST /api/heartbeat

Refresh the device's last_seen timestamp. A device is considered online if a heartbeat was received within 60 seconds.

GET /api/devices

List all devices with their status. Supports ?status=online|offline and ?q=keyword for filtering.
